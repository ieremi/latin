形容詞の比較級 (2) 不規則変化
===

| 原級 | 比較級 |
| --- | --- |
| bonus | melior, -ius |
| malus | peior, -ius |
| magnus | major, -jus |
| parvus | minor, minus |
| multum | plus |
| multi | plures, plura |
| vetus | vetustior, -ius |
| juvenis | junior |
| senex | senior |

# 辞書の見出し

major, majus

見出しが「-ior, -ius」の形で載っている形容詞は，比較級です．曲用は [comparative1.md](comparative1.md) のとおり，単数主格だけ特殊で，他は第 3 曲用子音幹に従います．

# 原級のない比較級

解剖学でよく使う superior, inferior, posterior, anterior は比較級ですが，原級はふつう使われません．

| 比較級 | 中性単数 | 原級 | 意味 |
| --- | --- | --- | --- |
| superior | superius | superus | 上の |
| inferior | inferius | inferus | 下の |
| posterior | posterius | posterus | 後ろの |
| anterior | anterius | ( 原級は残っていない ) | 前の |
