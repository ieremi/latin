接頭辞
===

- ab: 離れる
- ad: 「...へ，...のそばに」．下の「同化」を見ること
- ex: 「外へ，外に」
- inter: 間
- meta
- meso: 「中間の」．ギリシア語由来
- ob: 「...に向かって，...に逆らって」．b は次の子音に合わせて変わる（ oc-, of-, og-, op-, os- ）．occipitalis の oc- は ob- の b が c に同化した形
- peri: 「まわり」．ギリシア語由来
- pro: 「前へ，前に」．protuberantia, processus ( pro + cedo )
- re: 「うしろに，再び」
- semi: 「半分」．semispinalis, ductus semicircularis 半規管
- sub: 「下の，下位，副，補，少ない，亜」
- supra: 「上の」
- trans: 「越えて，横切って，わたって」．transversus ( trans + versus )
- tri: 「3」

# 同化

接頭辞の末尾の子音は，後ろに続く語の最初の子音に合わせて変わることがあります．これを同化と称します．

## ad

d が次の子音に合わせて変わります．

|次の子音|形|
|:---|:---|
|c, k, q|ac-|
|f|af-|
|g|ag-|
|l|al-|
|n|an-|
|p|ap-|
|r|ar-|
|s|as-|
|t|at-|
|sc, sp, st|a-|

- appendo 「つるす」( ap + pendo )
- accessorius 「副の」( ac + cess + orius )

## ob

b が次の子音に合わせて変わります．

|次の子音|形|
|:---|:---|
|c|oc-|
|f|of-|
|g|og-|
|p|op-|
|s|os-|

- occipitalis 「後頭の」( oc + cipit + alis )

## ex

b, d, g, j, l, m, n, r, v の前では e- になります．f の前では ef- になります．

## sub

c, f, g, p, r の前では，それぞれ suc-, suf-, sug-, sup-, sur- になります．

suspendo は sub + pendo ですが，sus- の形になっています．

# meso

ギリシア語 μέσος 「中間の」に由来します．後ろに母音が続くと mes- になります．

- mesenterium 「腸間膜」
- mesocolon 「結腸間膜」
- mesosalpinx 「卵管間膜」

# peri

ギリシア語 περί 「まわり」に由来します．

- pericardium 「心膜」
- peritoneum 「腹膜」

# re

「うしろに，再び」を表します．母音の前では red- になります．

- recedo 「しりぞく」( re + cedo )
- recessus 「陥凹」

# supra

「上の」を表します．

- supravesicalis 「膀胱の上の」

# tri

「3」を表します．

- triangularis 「三角形の」
