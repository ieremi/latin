# 痔帯, hemorrhoidal zone, zona hemorrhoidalis

## zona

第 1 曲用女性の名詞 zona 「帯」の単数主格です．

zona は，ギリシア語 ζώνη (zṓnē) 「帯」に由来します．

## hemorrhoidalis

第 3 曲用 i 幹 C の形容詞 hemorrhoidalis, -e 「痔の」の女性単数主格です．

hemorrhoidalis は hemorrhoid + alis です．

### hemorrhoid

ギリシア語 αἱμορροΐς (haimorrhoís) 「痔」の語幹に由来します．αἷμα (haîma) 「血」+ ῥέω (rhéō) 「流れる」からできた語です．

[https://en.wiktionary.org/wiki/haemorrhoides]

# 曲精細管, convoluted seminiferous tubules, tubuli seminiferi convoluti

## tubuli

第 2 曲用男性の名詞 tubulus, -i 「細管」の複数主格です．tubulus は tubus の指小辞形です．tubus は解説済です．

## seminiferi

第 1・2 曲用の形容詞 seminifer, -era, -erum 「精子を運ぶ」の男性複数主格です．

seminifer は semen の語幹 semin + i + fer です．fer は fero 「運ぶ」の語幹です．fero は解説済です．semen は解説済です．

[https://en.wiktionary.org/wiki/seminifer]

## convoluti

第 1・2 曲用の形容詞 convolutus, -a, -um 「巻かれた」の男性複数主格です．

convolutus は動詞 convolvo 「巻き合わせる」の完了受動分詞です．convolvo は con + volvo です．

[https://en.wiktionary.org/wiki/convolvo]
