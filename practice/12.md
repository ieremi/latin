# 心圧痕, cardiac impression, impressio cardiaca

本には impression cardiaca とありますが， impression は英語です．ラテン語では impressio です．

TA98 では impressio cardiaca として肺の用語に登録されています．

[https://ifaa.unifr.ch/Public/EntryPage/TA98%20Tree/Latin%20TA98/06.5.01.009%20Latin%20TA98.htm]

## impressio

第 3 曲用子音幹女性の名詞 impressio, -onis 「圧痕，押すこと」の単数主格です．

impressio は impress + io です．

### impress

第 3 活用の動詞 imprimo, imprimere, impressi, impressum 「押しつける，印象を与える」の目的分詞幹です．

imprimo は in + premo です．

#### in

「なかへ」を意味する接頭辞です．m の前では im に変わります．

#### premo

第 3 活用の動詞 premo, premere, pressi, pressum 「押す」です．

[https://en.wiktionary.org/wiki/imprimo]

### io

動詞の目的分詞幹に付いて，「...すること」を意味する女性名詞を作る接尾辞です．

## cardiaca

第 1・2 曲用の形容詞 cardiacus, -a, -um 「心臓の」の女性単数主格です．

cardiacus は cardi + acus です．

### cardi

「心臓」を意味するギリシア語名詞 kardia に由来します．

### acus

解説済です．

解剖学ラテン語では「心臓の」を表すために，形容詞 cardiacus を使うときと，第 3 曲用子音幹中性の名詞 cor 「心臓」の属格 cordis を使うときがあります ( 例: apex cordis 「心尖」)．使い分けの規準は明らかではありません．

## ostium

第 2 曲用中性の名詞 ostium 「口」の単数主格です．

ラテン語には os という綴りの中性名詞が 2 つあります．

- os, ossis 「骨」 ( 第 3 曲用子音幹 )

この 2 つは，つづりが同じだけで語源の異なる同綴異義語です．apex ossis coccygis の os は前者「骨」です．

一方 ostium, ostii 「戸口，入口，河口，( 器官の ) 口」は，第 2 曲用の名詞で， os, oris 「口」に由来する ( または同語源の ) 別の語です．体の開口部を表す解剖学用語では，第 3 曲用の os ではなく，この第 2 曲用の ostium が使われます．
